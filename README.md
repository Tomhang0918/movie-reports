## 数据

- [data/movies.csv](data/movies.csv) — 结构化观影数据，含年份、观看时间、片名、片源地、特效厅，不含金额与影院信息。

## 深度影评

按年份归档的长篇影评，见 `深度影评/`。

## 官方电子海报

按年份归档，见 `官方电子海报/`。报告中的海报按片名相对引用，例如 `官方电子海报/2026/闪灵.webp`。

## 线下实体海报

线下收藏的实体海报照片，按年份归档，见 `线下实体海报/`。

## 实体票根

实体票根照片，按年份归档，见 `实体票根/`。
